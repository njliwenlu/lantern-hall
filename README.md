# EvoArena: Lantern Hall

### [Try the live demo →](https://njliwenlu.github.io/lantern-hall/)

*A museum of impossible physics.* An AI explores a world without seeing its source, discovers its rules, and writes an executable reconstruction.

Watch two experiments, inspect the generated code, then challenge it with a live prediction.

**Result:** 48/48 held-out scenarios and 331/331 observations matched. Evidence from one small engine, not proof of universal equivalence.

## Run locally

Requires Node 22.18+.

```sh
npm install
npm run dev
```
